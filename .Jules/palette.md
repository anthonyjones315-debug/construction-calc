## 2026-04-15 - Interaction Confirmation Patterns
**Learning:** In tool-heavy calculator interfaces, immediate visual and ARIA feedback for copy actions prevents user doubt and redundant clicks. Using a 2-second state transition for "Copied" feedback is an effective pattern for this design system's glass-style components.
**Action:** Apply temporary state transitions (label + aria-label) to all 'Copy' and 'Save' interactions across the calculator suite.
