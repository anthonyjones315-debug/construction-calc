## 2026-04-11 - Copy Feedback Pattern
**Learning:** Providing immediate visual and screen-reader feedback for clipboard actions (like "Copy material list") improves perceived responsiveness. Using a 2-second state timer to toggle text to "COPIED" and update the aria-label ensures the interaction is clear and accessible.
**Action:** Apply this 2-second timer pattern for all copy-to-clipboard interactions in the design system.
