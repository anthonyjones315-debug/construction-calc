## 2025-05-14 - Copy to Clipboard Feedback Pattern
**Learning:** For utility actions like "Copy", users need immediate visual and audible/screen-reader confirmation. Using a "copied" state that swaps the button text to "COPIED" and updates the `aria-label` to "Copied to clipboard" provides clear feedback for all users.
**Action:** Use this state-based confirmation pattern for all "Copy" or "Save" actions where a full-page transition or notification isn't appropriate.
